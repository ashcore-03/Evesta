# EVESTA

EVESTA is a full-stack event discovery and management platform developed using Flutter, Django, and MySQL. The application helps users explore, manage, and interact with events through a modern mobile-friendly interface and real-time backend services.

---

## Features

- Event discovery and browsing
- User authentication and management
- Event coordination system
- Real-time event updates
- Backend API integration
- Database-driven event handling
- Mobile-friendly Flutter frontend
- Admin and coordinator modules

---

## Tech Stack

### Frontend
- Flutter

### Backend
- Python
- Django

### Database
- MySQL
